# Спрямляемые кривые
Пусть задана параметризация кривой: $\Gamma:\vec{r}(t), \ t \in [a; b]$, и мы хотим узнать длину кривой/носителя пути/дуги.

Поступим следующим образом: разобьём область изменения параметра $t$ следующим образом: $a = t_0 < t_1 < \dots < t_n = b$. В соответствии с областью изменения параметра изменится образуются точки на нашей дуги и каждой точке $t_{j}$ соответствует $r(t_{j})$. Соединим эти точки прямыми и длина получившейся ломаной по идее должна совпадать с искомой длиной дуги и чем больше таких дроблений, тем точнее такая оценка.

Пусть $T = \{t_k\}$, тогда $\sigma(T) = \sum_{j=0}^{n-1} |\vec{r}(t_{j+1}) - \vec{r}(t_j)|$ — длина ломаной, составленной из $t_{j}$
  
**Определение**: Кривая $\Gamma$ называется *спрямляемой*, если множество длин всех вписанных в кривую ломаных ограничено сверху, при этом *длиной* кривой $\Gamma$ называют следующую величину  
$$S(\Gamma) := \sup_{T} \sum_{j=0}^{n-1} |\vec{r}(t_{j+1}) - \vec{r}(t_j)|$$ 
**Теорема:** Пусть $\Gamma$ — гладкая кривая, $\vec{r}(t)$ — непрерывная и дифференцируемая параметризация, $\forall t:\vec{r}\,'(t) \neq 0$. Тогда кривая спрямляема и её длина выражается следующей формулой:  
$$S(\Gamma) = \int_{a}^{b} \sqrt{(x'(t))^2 + (y'(t))^2 + (z'(t))^2} \, dt$$  
Доказательство: 
1. Спрямляемость. Пусть $\vec{r}(t) = (x(t), y(t), z(t))$ непрерывно дифференцируема. Тогда
$\left. \begin{array}{l} x'(t) \\ y'(t) \\ z'(t) \end{array} \right\}$ — непрерывны на $[a; b]$. Из этого следует существование следующих величин: 
$\exists M_x = \max_{[a;b]} |x'(t)|, \ m_x = \min_{[a;b]} |x'(t)|$
$\exists M_y = \max_{[a;b]} |y'(t)|, \ m_y = \min_{[a;b]} |y'(t)|$
$\exists M_z = \max_{[a;b]} |z'(t)|, \ m_z = \min_{[a;b]} |z'(t)|$  

Посчитаем длину всех звеньев ломанной:
$$\sigma(T) = \sum_{j=0}^{n-1} \sqrt{(x(t_{j+1}) - x(t_j))^2 + (y(t_{j+1}) - y(t_j))^2 + (z(t_{j+1}) - z(t_j))^2} =$$
Поскольку $x,y,z$ - непрерывно дифференцируемые функции, то можем применить теорему Лагранжа. Сделаем это для всех 3 равенств:
$$=\sum_{j=0}^{n-1} \sqrt{(x'(\xi_j))^2 + (y'(\eta_j))^2 + (z'(\zeta_j))^2 (t_{j+1} - t_j)^{2}}, \ \ \xi_j, \ \eta_j, \ \tau_j \in (t_j; t_{j+1})$$
У нас нет никакой информации о точках $\xi_j, \ \eta_j, \tau_j$, ведь они прозвольные. Логично будет их оценить:
$$  
\begin{array}
& \sum_{j=0}^{n-1} \sqrt{m_x^2 + m_y^2 + m_z^2} (t_{j+1} - t_j) \le \sigma(T)\le \sum_{j=0}^{n-1} \sqrt{M_x^2 + M_y^2 + M_z^2} (t_{j+1} - t_j) \\
\sqrt{m_x^2 + m_y^2 + m_z^2} (b-a) \le \sigma(T) \le \sqrt{M_x^2 + M_y^2 + M_z^2} (b-a)
\end{array}  
$$
$\implies$ кривая $\Gamma$ спрямляема $\implies \sqrt{m_x^2 + m_y^2 + m_z^2} (b-a) \le S(T) \le \sqrt{M_x^2 + M_y^2 + M_z^2}(b-a)$
2. Дифференцируемость: 
![[Лекция 2 рис 2.png]]
Выберем параметр $t$ и зададим ему приращение как на рисунке. Мы знаем, что кривая гладкая, значит, существует $S(t)$ - длина кривой от точки $a$ до $t$. Получается, $S(t)$ является функцией, которая выражает эту длину.

Мы хотим показать, что длина выражается интегралом. Это равносильно тому, что производная длины равна подинтегральной функции.

Докажем, что функция $S(t)$ является дифференцируемой и также найдём её производную:

Пусть $S(t)$ - длина кривой от точки $a$ до точки $t$.
$S(\Delta\Gamma) = S(t+\Delta t) - S(t)$
Сейчас повторим доказательство первого пункта теоремы только с отрезком $[t;t+\Delta t]$.

Аналогично первому пункту введём следующие константы:
$\widetilde{M}_x = \max_{[t; t+\Delta t]} |x'(t)|, \widetilde{m}_x = \min_{[t; t+\Delta t]} |x'(t)|$  
$\widetilde{M}_y = \max_{[t; t+\Delta t]} |y'(t)|,\widetilde{m}_{y} = \min_{[t; t+\Delta t]} |y'(t)|$
$\widetilde{M}_z = \max_{[t; t+\Delta t]} |z'(t)|, \widetilde{m}_z = \min_{[t; t+\Delta t]} |z'(t)|$

  
$\sqrt{\widetilde{m}_x^2 + \widetilde{m}_y^2 + \widetilde{m}_z^2} |\Delta t| \le S(\Delta \Gamma) \le \sqrt{\widetilde{M}_x^2 + \widetilde{M}_y^2 + \widetilde{M}_z^2} |\Delta t|$  
  
$\sqrt{\widetilde{m}_x^2 + \widetilde{m}_y^2 + \widetilde{m}_z^2} \le \frac{S(t+\Delta t) - S(t)}{|\Delta t|} \le \sqrt{\widetilde{M}_x^2 + \widetilde{M}_y^2 + \widetilde{M}_z^2}$  
  
$\Delta t > 0, \ \Delta t \to 0$ (при $\Delta t < 0$ просто изменится знак)

$$
\sqrt{(x'(t))^2 + (y'(t))^2 + (z'(t))^2} \leq \lim_{\Delta t \to 0} \frac{s(t+\Delta t) - s(t)}{\Delta t} \leq \sqrt{(x'(t))^2 + (y'(t))^2 + (z'(t))^2}
$$

$$
s'(t) = \sqrt{(x'(t))^2 + (y'(t))^2 + (z'(t))^2}
$$

$$
s(\Gamma) = s(b) - s(a) = \int_a^b s'(t)\,dt = \int_a^b \sqrt{(x'(t))^2 + (y'(t))^2 + (z'(t))^2}\,dt
$$

$\vec{r}_1(t) = (x_1(t), y_1(t), z_1(t)), \quad t \in [a; b]$

$\vec{r}_2(\tau) = (x_2(\tau), y_2(\tau), z_2(\tau)), \quad \tau \in [\alpha; \beta]$

$$
\int_a^b \sqrt{(x_1'(t))^2 + (y_1'(t))^2 + (z_1'(t))^2}\,dt = \int_\alpha^\beta \sqrt{(x_2'(\tau))^2 + (y_2'(\tau))^2 + (z_2'(\tau))^2}\,d\tau
$$

Существует $\varphi(t)$ — непрерывно дифференцируемая строго монотонная функция: $[\alpha; \beta] \to [a; b]$

такая, что $\vec{r}_2(\varphi(t)) = \vec{r}_1(t)$
