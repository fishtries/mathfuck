$a = t_0 < t_1 < \dots < t_n = b$  
  
$T = \{t_k\}$  
  
$\delta(T) = \sum_{j=0}^{n-1} |\vec{r}(t_{j+1}) - \vec{r}(t_j)|$ — длина ломаной
  
**Определение**: Кривая — спрямляема, если множество длин всех вписанных в кривую ломаных ограничено.  
  
**Определение**: Длина кривой $S$ — верхняя грань длин вписанных ломаных.  
$S(\Gamma) = \sup_{T} \sum_{j=0}^{n-1} |\vec{r}(t_{j+1}) - \vec{r}(t_j)|$\\  
  
**Теорема:** Пусть $\Gamma$ — гладкая кривая, $\vec{r}(t)$ — непрер. и дифф, $\vec{r}\,'(t) \neq 0$. Тогда кривая спрямляема и её длина вычисл. формулой:  
$ S(\Gamma) = \int_{a}^{b} \sqrt{(x'(t))^2 + (y'(t))^2 + (z'(t))^2} \, dt $\\  
\textbf{Доказательсво теоремы:}\\  
  
\textit{Комментарий Qwen: Здесь вводится основное понятие длины кривой как предела длин вписанных ломаных (если он существует).  
Теорема дает практический способ вычисления этой длины для гладких кривых через определенный интеграл.}  
  
  
  
$ \left. \begin{array}{l} x'(t) \\ y'(t) \\ z'(t) \end{array} \right\} $ — непрерывны на $[a; b]$. Из этого следует существование следующих велечин:  
  
$ \exists \ M_x = \max_{[a;b]} |x'(t)|, \ m_x = \min_{[a;b]} |x'(t)| $\\  
$ M_y = \max_{[a;b]} |y'(t)|, \ m_y = \min_{[a;b]} |y'(t)| $\\  
$ M_z = \max_{[a;b]} |z'(t)|, \ m_z = \min_{[a;b]} |z'(t)| $  
  
$ \delta(T) = \sum_{j=0}^{n-1} \sqrt{(x(t_{j+1}) - x(t_j))^2 + (y(t_{j+1}) - y(t_j))^2 + (z(t_{j+1}) - z(t_j))^2} = $  
$ = (\text{по Т. Лагранжа}) =\\  
= \sum_{j=0}^{n-1} \sqrt{(x'(\xi_j))^2 + (y'(\eta_j))^2 + (z'(\zeta_j))^2 (t_{j+1} - t_j)}$\\  
  
\framebox{$ \xi_j, \ \eta_j, \ \zeta_j \in (t_j; t_{j+1}) $}\\  
  
$ \sum_{j=0}^{n-1} \sqrt{m_x^2 + m_y^2 + m_z^2} (t_{j+1} - t_j) \le \delta(T) \le \\  
\le \sum_{j=0}^{n-1} \sqrt{M_x^2 + M_y^2 + M_z^2} (t_{j+1} - t_j) $\\  
  
$ \sqrt{m_x^2 + m_y^2 + m_z^2} (b-a) \le \delta(T) \le \sqrt{M_x^2 + M_y^2 + M_z^2} (b-a) $  
  
$ \dots \le S(\Gamma) \le \dots $  
  
$ \Rightarrow $ кривая спрямляема  
  
\textit{Комментарий Qwen: В этом блоке доказывается, что для гладкой кривой длины вписанных ломаных ограничены, а значит, кривая спрямляема. Используется теорема Лагранжа о среднем значении для каждой координатной функции на отрезке [t_j,t_{j+1}].}

Докажем, что функция длины дифференцируема:\\  
$ \frac{\Delta S(t)}{\Delta t} = \frac{S(t+\Delta t) - S(t)}{\Delta t} $ отрезок: $[t; t+\Delta t]$\\  
  
$ \widetilde{M}_x = \max_{[t; t+\Delta t]} |x'(t)| \quad \widetilde{m}_x = \min_{[t; t+\Delta t]} |x'(t)| $  
для $ \widetilde{M}_y, \widetilde{M}_z, \widetilde{m}_y, \widetilde{m}_z $ вводятся аналогично.\\  
  
$ \sqrt{\widetilde{m}_x^2 + \widetilde{m}_y^2 + \widetilde{m}_z^2} |\Delta t| \le S(\Delta \Gamma) \le \sqrt{\widetilde{M}_x^2 + \widetilde{M}_y^2 + \widetilde{M}_z^2} |\Delta t| $  
  
$ \sqrt{\widetilde{m}_x^2 + \widetilde{m}_y^2 + \widetilde{m}_z^2} \le \frac{S(t+\Delta t) - S(t)}{|\Delta t|} \le \sqrt{\widetilde{M}_x^2 + \widetilde{M}_y^2 + \widetilde{M}_z^2} $  
  
$ \Delta t > 0, \ \Delta t \to 0 $ (при $\Delta t < 0$ просто изменится знак)
