# Норма. Шары и окрестности в $R^n$
***Определение***: Пусть X - некоторое линейное пространство и  $\forall x \in X$ поставлено в соответствие некоторое число (скаляр,вещественное) $\phi(x) \in \mathbb{R}$ (**или $||x||_{i}$** где $i$ -целое число) и для $\phi(x)$ выполнены следующие свойства:
1. $\phi(x) \geq 0, \forall x \in X. \text{Причём } \phi(x) = 0 \Leftrightarrow x=0$ - Длина неотрицательна
2.  $\phi(\alpha x)=|\alpha|\phi(x), \forall x \in X, \forall\alpha \in \mathbb{R}$ - Растяжение длины (т.е. можно вынести число по модулю)
3. 3. $\phi(x+y) \leq \phi(x) + \phi(y), \forall x,y \in X$ - Неравенство треугольника
Если выполнены все свойства, то $\phi(x)$ - **норма**, а пространство X - **нормированное**.

Для вектора $x = (x_{1},\dots,x_{n})$ рассмотрим 4 вида нормы:
1. Евклидова норма: $||x||_{2} = \sqrt{ x_{1}^{2}+\dots+x_{n}^{2} }$
2. Манхэттенская норма: $||x||_{1} = |x_{1}| + \dots + |x_{n}|$
3.  Обобщённый вариант: $||x||_{p} = \left(\sum^{n}_{j=1}|x_{j}|^{p}\right)^{\frac{1}{p}}$, при $p\geq 1$
