# Норма. Шары и окрестности в $R^n$
***Определение***: Пусть X - некоторое линейное пространство и  $\forall x \in X$ поставлено в соответствие некоторое число (скаляр,вещественное) $\phi(x) \in \mathbb{R}$ (**или $||x||_{i}$** где $i$ -целое число) и для $\phi(x)$ выполнены следующие свойства:
1. $\phi(x) \geq 0, \forall x \in X. \text{Причём } \phi(x) = 0 \Leftrightarrow x=0$ - Длина неотрицательна
2.  $\phi(\alpha x)=|\alpha|\phi(x), \forall x \in X, \forall\alpha \in \mathbb{R}$ - Растяжение длины (т.е. можно вынести число по модулю)
3. 3. $\phi(x+y) \leq \phi(x) + \phi(y), \forall x,y \in X$ - Неравенство треугольника
Если выполнены все свойства, то $\phi(x)$ - **норма**, а пространство X - **нормированное**.

Для вектора $x = (x_{1},\dots,x_{n})$ рассмотрим 4 вида нормы:
1. Евклидова норма: $||x||_{2} = \sqrt{ x_{1}^{2}+\dots+x_{n}^{2} }$
2. Манхэттенская норма: $||x||_{1} = |x_{1}| + \dots + |x_{n}|$
3.  Общий вид для норм: $||x||_{p} = \left(\sum^{n}_{j=1}|x_{j}|^{p}\right)^{\frac{1}{p}}$, при $p\geq 1$
4. Норма на бесконечности: $||x||_{\infty} = \underset{1 \leq j \leq n}{max}|x_{j}|$

Проверим, что манхэттенская норма является нормой, воспользовавшись 3 свойствами для норм:
1. $Необходимость:$ Очевидно, что сумма модулей не превосходит ноль, так как результат модуля по определению неотрицателен. $Достаточность:$ Пусть $\phi(x) = 0$. Так как модуль неотрицателен, то достижения 0 суммой модулей возможен при нулевом векторе.
2. $\phi(\alpha x) = |\alpha x_{1}|+\dots+|\alpha x_{n}| = |\alpha|(|x_{1}|+\dots+|x_{n}|) = |\alpha| \phi(x)$
3. $\phi(x+y)=|x_{1}+y_{1}|+\dots+|x_{n}+y_{n}|\overset{\text{по свойству } |x+y| \leq |x|+|y|}{\leq}|x_{1}|+|y_{1}|+\dots+|x_{n}|+|y_{n}| = \phi(x)+\phi(y)$
Аналогичные доказательства и для других видов норм.

Свойство модулей, которое понадобилось нам для доказательства 3 свойства манхэттенской нормы, всего лишь частный случай **Неравенства Минковского:** $$
\begin{matrix}
\left(\sum_{j=1}^{n} |x_j + y_j|^{p}\right)^{\frac{1}{p}} \leq \left(\sum_{j=1}^{n} |x_j|^p\right)^{\frac{1}{p}} + \left(\sum_{j=1}^{n} |y_j|^p\right)^{\frac{1}{p}}, \quad p \geq 1 \\
ИЛИ \\
||x+y||_{p} \leq ||x||_{p} + ||y||_{p}, \ p\geq 1
\end{matrix}
$$
