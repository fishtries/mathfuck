# Сходимость последовательностей в $R^n$
Пространство $R^n$.  $$x^{(1)} = (x_{1}^{(1)},x_{2}^{(1)},\dots x_{n}^{(1)}) 
$$ $$x^{(2)} = (x_{1}^{(2)},x_{2}^{(2)},\dots x_{n}^{(2)})$$ 
 
**Определение:** Последовательность $x^{(k)}$ n-мерных векторов называют **сходящейся к вектору $a$**, если норма разности $|| x^{k} - a|| \to 0$, при $k \to \infty$.

Пример доказательства сходимости к точке a: 
$x^{(k)} = (\frac{1}{k},\frac{k^2}{k^2+1}) \to a = (0;1)$
Если мы возьмём k = 1,2,3 (чтобы понять как ведут: $\frac{1}{k}, \frac{k^2}{k^2 +1}$ нам нужны возрастающие значения для k. Позже мы будем просто использовать предел при $k \to \infty$) то значения выглядят так:
$x^{(1)} = (1, \frac{1}{2})$
$x^{(2)} = (\frac{1}{2}, \frac{4}{5})$
$x^{(3)} = (\frac{1}{3}, \frac{9}{10})$
Предположительно  правда $x^{(k)} \to (0;1)$, но теперь давайте докажем это по определению, используя норму $||x||_{1} = |x_{1}| + |x_{2}|$($x_{1},x_{2}$ - компоненты вектора x).
$||x^{(k)} - a|| =|\frac{1}{k} - 0| + |\frac{k^2}{k^2 +1} -1| =$ 
$=|\frac{1}{k}| + |\frac{1}{k^2 +1}|  \to 0; k \to \infty$, ч.т.д.

$=|\alpha| \underbrace{\|x^{(k)} - a\|}_{\to 0} + |\beta| \underbrace{\|y^{(k)} - b\|}_{\to 0} \to 0$
