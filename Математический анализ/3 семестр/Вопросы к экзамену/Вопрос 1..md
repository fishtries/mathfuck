# Линейное пространство $R^n$
***Определение***: вектор пространства $R^n$ - упорядоченный набор из n компонент (компоненты вектора - числа из поля R).

Пусть вектор x = ($x_{1}$, $x_{2}$, ..., $x_{n}$) и вектор y =  ($y_{1}$, $y_{2}$, ..., $y_{n}$). Тогда **для векторов x и y определим следующие операции**:
1. Сумма векторов: x + y = ($x_{1}$ + $y_{1}$, $x_{2}$ + $y_{2}$, ..., $x_{n}$ + $y_{n}$)
2. Произведение вектора на число из поля: $a$x =  ($a$$x_{1}$, $a$$x_{2}$, ..., $a$$x_{n}$), где $a$ ∈ R. (В данном случае у нас числа из поля R, но они могут быть из любого поля)

***Определение***: Линейным пространством $R^n$ называют множество n-мерных векторов над полем вещественных чисел, на котором заданы операции сложения векторов и умножения вектора на число из поля, удовлетворяющее следующим свойствам-аксиомам:
1. x+y = y+x (Коммутативность сложения)
2. (x+y)+z = x+(y+z) (Ассоциативность сложения)
3. ∃ 0: x+0=0+x=x (Существование нулевого элемента)
4. ∃ -x : (-x) + x = 0 (Существование противоположного элемента)
5. ∃ 1: x $\cdot$ 1 = 1 $\cdot$ x = x (Существование единичного элемента)
6.  $a$(x+y) = $a$x + $a$y (Дистрибутивность с векторами)
7. ($a$ + $b$)x = $a$x + $b$x (Дистрибутивность с векторами)
8. ($a$$b$)x = $a$($b$x) (Ассоциативность умножения)

Назовём набор n векторов *последовательностью или системой векторов* и обозначим следующим образом:
$$
\begin{matrix}
x^{(k)} = {(x_{1}^{(k)},\dots,x_{n}^{(k)})} \\
ИЛИ \\
\{ x^{(k)} \} = (x^{(1)},\dots,x^{(k)})
\end{matrix}
$$
Где $x_{i}^{(k)}$ или $x^{(i)}$- вектора системы.

***Определение***: Назовём выражение  $a_{1} x_{1}^{(k)}$ + ... + $a_{n} x_{n}^{(k)}$ **линейной комбинацией векторов**, где $a_{1}$, ..., $a_{n}$ - коэффициенты.

***Определение***: Система векторов  $x^{(k)}$ - **линейно независимая** (ЛНЗ), если линейная комбинация  $a_{1} x_{1}^{(k)}$ + ... + $a_{n} x_{n}^{(k)}$ = 0, только если все коэффициенты равны 0 ($a_{1}=\dots =a_{n}=0$). В противном случае система - **линейно зависимая** (ЛЗ).

***Определение***: пространство называют *n-мерным* (конечномерным), если в нём существует ЛНЗ система векторов и при этом всякая система из n+1 векторов уже ЛЗ.

***Определение***: Базис - максимальная, порождающая всё пространство ЛНЗ система векторов.
**Стандартным базисом** пространства $R^n$ назовём: $$e_{1}(1,0, \dots,0),\ e_{2}(0,1,0\dots,0), \dots , \ e_{n}(0,0,\dots,0,1) $$
***Определение***: для вектора x в базисе $e_{1}, \dots, e_{n}$ линейная комбинация $a_{1}e_{1} +\dots + a_{n}e_{n}$ = x. Где $a_{1},\dots ,a_{n}$ - координаты вектора x относительно базиса $e_{1}, \dots, e_{n}$.
