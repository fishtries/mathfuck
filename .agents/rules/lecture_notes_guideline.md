# Правила конспектирования и оцифровки лекций (Workspace Rule)

Всегда следуйте инструкциям из [AGENTS.md](file:///home/fish/Documents/mathfuck/syncing/AGENTS.md).

### Краткий чек-лист при написании конспекта:
1. **Первая строка:** ровно одна ссылка `[[Название предмета семестр - HOME]]`.
2. **Заголовки:** **ТОЛЬКО один `#` (H1)** для разделов темы (`# Счетные множества`, `# Измеримые множества`).
3. **Определения:** `**Определение**: Понятие называют *термин_курсивом*, если...`.
4. **Теоремы и доказательства:** `**Теорема (Название)**:`, доказательство с `($\implies$)` и аннотациями `\overset{...}{=}`, `\underbrace{...}_{\to 0}`.
5. **LaTeX:** Никакого русского текста без `\text{...}` внутри математики. Использовать `\|x\|`, `\langle ... \rangle`, `\varnothing`.
6. **Подача:** Сохранять живые рассуждения и аналогии лектора («Вот смотрите...», «Пронумеровать, но не посчитать»).
7. **Медиа:** Ссылки вида `![[Лекция X рис Y.png]]` без префиксов папок.
8. **Ошибки и сомнения:** Оформлять в кодовый блок ` ``` `.
