# Формула алгебры высказываний.

**Определение**: *Формулой алгебры* высказываний называют выражение, составленное из пропозициональных элементов знаков логических операций и скобок по следующим правилам:

1. Пропозициональная переменная — есть формула.
2. Если А — формула, то $\overline{A}$ — также формула.
3. Если А и В — формулы, то А конъюнкция / дизъюнкция / импликация / эквиваленция B.
4. Никаких других формул, кроме указанных в 1–3 — нет.

**Определение**: Переменная область значений, которая состоит из всевозможных высказываний, называется *пропозициональной*.

**Определение**: *Подформула* формула алгебры высказываний называется всякая часть формулы, которая сама является формулой.

**Определение**: Для каждой формулы существует конечная последовательность всех её подформул, начинающейся входящих в данную формулу пропозициональных переменных (далее ПП) и заканчивающееся самой исходной формулой такая, что каждый член этой последовательности, не являющейся ПП, есть либо отрицание уже имеющегося члена последовательности, либо получаемой из двух уже имеющихся членов последовательности их соединением с помощью первого из знаков логической операции ($\wedge, \vee, \implies,\iff$) и заключением, полученного выражений в скобки. Такую последовательность будем называть *порождающей последовательностью*.

Например: $((A \overset{2}{\to} B) \overset{3}{\cdot} C \overset{4}{\lor} B \overset{5}{\iff} A) \overset{6}{\cdot} \overset{1}{\overline{C}}$

ПП: A, B, C, $\overline{C}$, $A \rightarrow B$, $(A \rightarrow B) \cdot C$, $(A \rightarrow B) \cdot C \lor B$, $(A \rightarrow B) \cdot C \lor B \leftrightarrow A$, $((A \rightarrow B) \cdot C \lor B \leftrightarrow A) \cdot \overline{C}$ — порождающие.

**Теорема**: Всевозможные значения формулы, определяются как истинностные, к-ые состоят из 2^k строк, где k — кол-во переменных (ПП)
