# Формула алгебры высказываний.

**Определение**: *Формулой алгебры* высказываний называют выражение, составленное из пропозициональных элементов знаков логических операций и скобок по следующим правилам:

1. Пропозициональная переменная — есть формула.
2. Если А — формула, то $\overline{A}$ — также формула.
3. Если А и В — формулы, то А конъюнкция / дизъюнкция / импликация / эквиваленция B.
4. Никаких других формул, кроме указанных в 1–3 — нет.

**Определение**: Переменная область значений, которая состоит из всевозможных высказываний, называется *пропозициональной*.

**Определение**: *Подформула* формула алгебры высказываний называется всякая часть формулы, которая сама является формулой.

**Определение**: Для каждой формулы существует конечная последовательность всех её подформул, начинающейся входящих в данную формулу пропозициональных переменных (далее ПП) и заканчивающееся самой исходной формулой такая, что каждый член этой последовательности, не являющейся ПП, есть либо отрицание уже имеющегося члена последовательности, либо получаемой из двух уже имеющихся членов последовательности их соединением с помощью первого из знаков логической операции ($\wedge, \vee, \implies,\iff$) и заключением, полученного выражений в скобки. Такую последовательность будем называть *порождающей последовательностью*.

Например: $((A \overset{2}{\to} B) \overset{3}{\cdot} C \overset{4}{\lor} B \overset{5}{\iff} A) \overset{6}{\cdot} \overset{1}{\overline{C}}$

ПП: A, B, C, $\overline{C}$, $A \rightarrow B$, $(A \rightarrow B) \cdot C$, $(A \rightarrow B) \cdot C \lor B$, $(A \rightarrow B) \cdot C \lor B \leftrightarrow A$, $((A \rightarrow B) \cdot C \lor B \leftrightarrow A) \cdot \overline{C}$ — порождающие.

**Теорема**: Всевозможные значения формулы, описываются как истинностные, которые состоят из $2^{n}$ строк, где n — кол-во переменных (ПП)

# Виды формул и их классификация
**Определение**: Формула, принимающая значение истина при любых значениях входящих в неё П.П., наз. *тождественно истинной, тавтологией* или *общезначимой*. 

**Определение**: Формула, принимающая значение ложь при любых значениях входящих в неё П.П., называется *тождественно ложной* или *противоречивой*.

**Определение**: Формула, принимающая значение истина при некоторых значениях входящих в неё П.П., называется *выполнимой*.

**Замечание**: Любая тождественно ложная формула также является выполнимой.

**Определение**: Формула, принимающая значение ложь при некоторых значениях входящих в неё П.П., называется *опровержимой*.

**Замечание**: Любая тождественно ложная формула также является опровержимой. Обратное неверно!

# Тавтология алгебры высказываний
**Теорема (о подстановках)**: Если формула В, содержащая П.П. x: В = В(x, y, ...), является тавтологией, то подстановка в формулу В вместо П.П. x любой другой формулы снова приводит к тавтологии.

**Пример**: $B = X \lor \overline{X} \lor Y$

| X   | Y   | $X \lor \overline{X} \lor Y$ |
| --- | --- | ---------------------------- |
| И   | И   | И                            |
| И   | Л   | И                            |
| Л   | И   | И                            |
| Л   | Л   | И                            |
⇒ $X \lor \overline{X} \lor Y$ — тавтология.

**Теорема (о выводе тавтологий из тавтологий)** **(правило заключений)**: Если формула A и A → B является тавтологией, то формула B тоже является тавтологией.

f A; ⊢ A → B; ⇒ ⊢ B.

Д-во: П.к. A; A → B. ⇒ ⊢ (тавтологии), то по опр., эти ф-лы принимают значение истина при любых входящих в них П.П. Тогда: A = T (true) A → B = T.

T → B = T ⇒ B = T.  
тавтологии ⇒ ⊢ B.   ч.т.д.

Примеры тавтологических импликаций:

1) ⊢ A·B → A  
2) ⊢ A → A ∨ B  
3) ⊢ A·(A → B) → B.  (modus ponens / правило заключения)  
4) ⊢ B·(A → B) → A  (modus tollens)  
5) ⊢ A·(A ∨ B) → B.
